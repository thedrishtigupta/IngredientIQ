# Research Paper

The IngredientIQ research paper, in the department's paper format: single column, blue headings, a literature survey table, grid tables with captions below, and numbered references with DOI links. The method and findings are described in [docs/RESEARCH.md](../docs/RESEARCH.md).

| File | Content |
|---|---|
| `main.tex` | The paper |
| `main_10page.tex` | Condensed version for a 10-page limit: same findings and references, shorter prose, compact tables (`tables/*_compact.tex`). Build it like `main.tex`. |
| `references.tex` | Numbered references. [1] to [15] are the literature survey, with the same numbers as Table 1. |
| `figures/`, `tables/` | Generated by `scripts/make_paper_assets.py`. Do not edit by hand. |

## Build

**Overleaf (recommended, so all three of you can edit together).**
1. Zip the whole `paper/` folder, including `figures/` and `tables/`.
2. In Overleaf, choose New Project, then Upload Project.
3. Set the compiler to pdfLaTeX.

**Local.** Use any TeX distribution, then run `latexmk -pdf main.tex`.

The font is Carlito, a free clone of the template's Calibri; Overleaf has it.

## Never type a result by hand

Every number, table and figure is generated from the pipeline:

```powershell
python scripts/run_research.py           # main study, about 1 hour
python scripts/run_robustness.py         # ablation, per-category models, sensitivity, about 30 minutes
python scripts/make_paper_assets.py      # figures/*.pdf, tables/*.tex, tables/numbers.tex
```

- In prose, use the macros from `tables/numbers.tex`, e.g. `\NAnalysed{}` or `\NRobust{}`. Never type the digits.
- If you need a number that has no macro, add it to `numbers()` in [scripts/make_paper_assets.py](../scripts/make_paper_assets.py).
- If you change the pipeline, rerun all three scripts and re-upload `figures/` and `tables/`.

## House style

- **No em dashes** anywhere. Use a comma, colon, semicolon or parentheses instead.
- En dashes (`--` in LaTeX) are used only for number ranges (`pp.~345--354`) and two-person names (Mann--Whitney).

## Section status

| Colour | Meaning | What you do |
|---|---|---|
| **Blue** text | AI-drafted: abstract, introduction, literature survey (table and text), interpretation paragraphs, discussion, limitations, conclusion, acknowledgment | Rewrite in your own words; keep the facts, number macros and citations |

## Literature survey

Every one of the 15 papers in Table 1 was checked against Crossref (the DOI registry) or the publisher's page: authors, title, venue, volume, pages and DOI. Each "Key Findings" entry paraphrases that paper's own abstract.

**You still need to read them.** A paraphrase of an abstract is not a reading. Open each paper, check that the key finding and the sentence citing it say what the paper says, and adjust anything that doesn't. You will be asked about them in the viva.

Make sure every one of you can explain every sentence. If you can't defend a sentence, cut it.
